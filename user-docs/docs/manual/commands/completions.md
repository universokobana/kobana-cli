# kobana completions

Gera o autocompletar para o shell

```text
kobana completions <SHELL>
```

**Argumentos**

| | Descrição |
|---|---|
| `<SHELL>` | Shell para o qual gerar o autocompletar (bash, zsh, fish, powershell, elvish) |
