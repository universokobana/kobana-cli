# kobana schema

Mostra o schema da API de um endpoint

```text
kobana schema [OPÇÕES] [ENDPOINT]
```

**Argumentos**

| | Descrição |
|---|---|
| `[ENDPOINT]` | Caminho do endpoint (ex.: banking.charge.pix.create, inbox.emails.list) |


**Opções**

| | Descrição |
|---|---|
| `--list` | Lista os produtos e recursos disponíveis |
