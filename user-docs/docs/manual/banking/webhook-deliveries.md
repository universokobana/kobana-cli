# kobana banking webhook-deliveries


Comandos de `kobana banking webhook-deliveries`. Toda opção global ([Opções globais](/manual/commands/global-options)) vale aqui.

| Comando | HTTP | Descrição |
|---|---|---|
| [`webhook-deliveries resend`](#webhook-deliveries-resend) | `PUT /v1/webhook_deliveries/resend` | Reenviar Webhooks Enviados |
| [`webhook-deliveries list`](#webhook-deliveries-list) | `GET /v1/webhook_deliveries` | Listar Webhooks Enviados |
| [`webhook-deliveries get`](#webhook-deliveries-get) | `GET /v1/webhook_deliveries/{id}` | Informações do Webhook Enviado |

## webhook-deliveries resend

Reenviar Webhooks Enviados

```text
kobana banking webhook-deliveries resend [OPÇÕES]
```

`PUT /v1/webhook_deliveries/resend`

Reenviar webhooks enviados.

Está limitado aos primeiros 1000 encontrados na busca conforme os parâmetros.

O `ID do Objeto` vai retornar todos e qualquer tipo de objeto que tenha o ID enviado, ou seja, se você enviar 1, poderá retornar boletos, clientes e etc. Caso queira um filtro mais refinado, combine o `ID do Objeto` com o `Código do evento`.

Quando `created_from` não é informado, a busca considera só os últimos 12 meses — a retenção de `webhook_deliveries` é de 12 meses, então não há registro mais antigo que isso para ser encontrado.
