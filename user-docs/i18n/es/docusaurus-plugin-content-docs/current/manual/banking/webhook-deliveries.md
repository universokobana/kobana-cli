# kobana banking webhook-deliveries


Comandos de `kobana banking webhook-deliveries`. Toda opción global ([Opciones globales](/manual/commands/global-options)) vale aquí.

| Comando | HTTP | Descripción |
|---|---|---|
| [`webhook-deliveries resend`](#webhook-deliveries-resend) | `PUT /v1/webhook_deliveries/resend` | Reenviar Webhooks Enviados |
| [`webhook-deliveries list`](#webhook-deliveries-list) | `GET /v1/webhook_deliveries` | Listar Webhooks Enviados |
| [`webhook-deliveries get`](#webhook-deliveries-get) | `GET /v1/webhook_deliveries/{id}` | Información del Webhook Enviado |

## webhook-deliveries resend

Reenviar Webhooks Enviados

```text
kobana banking webhook-deliveries resend [OPCIONES]
```

`PUT /v1/webhook_deliveries/resend`

Reenviar webhooks enviados.

Está limitado a los primeros 1000 encontrados en la búsqueda según los parámetros.

El `ID del Objeto` devolverá todos y cualquier tipo de objeto que tenga el ID enviado, es decir, si envía 1, puede devolver boletos, clientes, etc. Si desea un filtro más refinado, combine el `ID del Objeto` con el `Código del evento`.
