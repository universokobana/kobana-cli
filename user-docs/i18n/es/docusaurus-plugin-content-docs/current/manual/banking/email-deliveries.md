# kobana banking email-deliveries


Comandos de `kobana banking email-deliveries`. Toda opción global ([Opciones globales](/manual/commands/global-options)) vale aquí.

| Comando | HTTP | Descripción |
|---|---|---|
| [`email-deliveries list`](#email-deliveries-list) | `GET /v1/email_deliveries` | Listar Correos Electrónicos Enviados |
| [`email-deliveries get`](#email-deliveries-get) | `GET /v1/email_deliveries/{id}` | Información del Correo Electrónico Enviado |
| [`email-deliveries resend`](#email-deliveries-resend) | `PUT /v1/email_deliveries/{id}/resend` | Reenviar Correo Electrónico Enviado |

## email-deliveries list

Listar Correos Electrónicos Enviados

```text
kobana banking email-deliveries list [OPCIONES]
```

`GET /v1/email_deliveries`

## email-deliveries get

Información del Correo Electrónico Enviado

```text
kobana banking email-deliveries get [ID] [OPCIONES]
```

`GET /v1/email_deliveries/{id}`

Consulta información específica de un correo electrónico enviado

**Argumentos de la ruta:** `id`

**Respuestas**

| HTTP | Descripción |
|---|---|
| `200` | Correo electrónico encontrado con éxito |
| `404` | Correo electrónico no encontrado |

## email-deliveries resend

Reenviar Correo Electrónico Enviado

```text
kobana banking email-deliveries resend [ID] [OPCIONES]
```

`PUT /v1/email_deliveries/{id}/resend`

**Respuestas**

| HTTP | Descripción |
|---|---|
