# kobana art

Muestra el arte de Kobana en el terminal; sin comando, la cigüeña

```text
kobana art [OPCIONES] [COMANDO]
```

**Comandos**

| | Descripción |
|---|---|
| `kadu` | Kadu, fiel a la foto (55 × 44) |
| `anim` | Kadu se balancea, sonríe y parpadea, durante unos 6 s (48 × 37) |
| `logo` | Logo de Kobana (64 × 6) |
| `cegonha` | La cigüeña de Kobana (96 × 32) |
