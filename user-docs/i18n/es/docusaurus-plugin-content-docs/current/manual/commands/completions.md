# kobana completions

Genera el autocompletado para el shell

```text
kobana completions <SHELL>
```

**Argumentos**

| | Descripción |
|---|---|
| `<SHELL>` | Shell para el que generar el autocompletado (bash, zsh, fish, powershell, elvish) |
