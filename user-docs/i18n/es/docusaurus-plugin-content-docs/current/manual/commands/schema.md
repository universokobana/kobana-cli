# kobana schema

Muestra el schema de la API de un endpoint

```text
kobana schema [OPCIONES] [ENDPOINT]
```

**Argumentos**

| | Descripción |
|---|---|
| `[ENDPOINT]` | Ruta del endpoint (ej.: banking.charge.pix.create, inbox.emails.list) |


**Opciones**

| | Descripción |
|---|---|
| `--list` | Lista los productos y recursos disponibles |
