# kobana banking webhook-deliveries

| Command | HTTP | Description |
|---|---|---|
| [`webhook-deliveries resend`](#webhook-deliveries-resend) | `PUT /v1/webhook_deliveries/resend` | Resend Sent Webhooks |

## webhook-deliveries resend

Resend Sent Webhooks

```text
kobana banking webhook-deliveries resend [OPTIONS]
```

`PUT /v1/webhook_deliveries/resend`

Resend sent webhooks.

It is limited to the first 1000 found in the search according to parameters.

The `Object ID` will return all and any type of object that has the sent ID, that is, if you send 1, it may return billets, customers, etc. If you want a more refined filter, combine the `Object ID` with the `Event Code`.
