# kobana schema

Introspect API schema for an endpoint

```text
kobana schema [OPTIONS] [ENDPOINT]
```

**Arguments**

| | Description |
|---|---|
| `[ENDPOINT]` | Endpoint path (e.g., banking.charge.pix.create, inbox.emails.list) |


**Options**

| | Description |
|---|---|
| `--list` | List available products and resources |
