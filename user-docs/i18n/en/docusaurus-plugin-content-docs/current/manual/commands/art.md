# kobana art

Show the Kobana art in the terminal; with no command, the stork

```text
kobana art [OPTIONS] [COMMAND]
```

**Commands**

| | Description |
|---|---|
| `kadu` | Kadu, true to the photo (55 × 44) |
| `anim` | Kadu sways, smiles and blinks, for about 6 s (48 × 37) |
| `logo` | The Kobana logo (64 × 6) |
| `cegonha` | The Kobana stork (96 × 32) |
